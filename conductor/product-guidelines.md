# Product Guidelines: Pete Suggitt Personal Site (`suggitpe.github.io`)

## Brand Voice & Tone
- **Pragmatic & Clear**: Written in a straightforward, professional tone suitable for technical blogs and architectural notes.
- **Approachable & Welcoming**: Friendly and accessible for friends, colleagues, and casual visitors exploring recipes or talks.

## UX & Visual Design Principles
- **Dual Device Optimization (Laptop & Phone)**: The user base is a balanced mix of laptop/desktop users and smartphone users. Layouts must provide an ergonomic desktop experience (e.g. side navigation, wide reading containers) and a fluid mobile experience (e.g. touch-friendly navigation, mobile header, auto-wrapping cards).
- **Readability First**: Prioritize typography, strong contrast, clean spacing, and uncluttered content presentation.
- **Preview-First Proposals**: Any visual redesign or UI layout proposal MUST be provided as a standalone preview page (`preview.html` or browser artifact) for user evaluation before committing actual changes to production files.
- **Human-in-the-Loop Pre-Commit Approval**: All change sets, file diffs, and commit messages MUST be presented to the user for explicit review and approval prior to running any git commit or push commands.
- **Lightweight Footprint**: Rely on clean semantic HTML, lightweight CSS, and standard Jekyll site generation for maximum load speed and reliability.
