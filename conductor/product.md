# Product Definition: Pete Suggitt Personal Site (`suggitpe.github.io`)

## Vision
A clean, reliable personal hub and digital garden hosted on GitHub Pages. It serves as Pete Suggitt's online presence, sharing technical blog posts, presentations, and culinary recipes with friends, colleagues, and technology enthusiasts.

## Primary Goals
- **Personal Hub & Bio**: Provide a clear, professional, and accessible personal landing page.
- **Knowledge Sharing**: Publish engineering insights, architecture patterns, and technical notes via blog posts.
- **Talk Showcase**: Organize and index presentations and speaking engagements.
- **Culinary Collection**: Maintain a structured recipe collection grouped by category.

## Target Audience & Device Mix
- **Audience**: Friends, colleagues, technology professionals, and food/cooking enthusiasts.
- **Device Profile**: Primary users browse on a mix of **laptops** (desktop displays) and **mobile phones**. All layouts, menus, typography, and interactive components must deliver a seamless experience across both mobile and desktop viewports.

## Core Requirements & Operating Principles
- **Preview-First Proposals**: All proposed UI/UX, styling, or feature changes must first be presented as a standalone preview page (`preview.html` or proposal preview artifact) for user review prior to making actual changes to main repository files.
- **Human-in-the-Loop Pre-Commit Approval**: Every change set, diff, and commit message must be reviewed and explicitly approved by the user before executing any git commit or push command.
- **Static & Fast**: Built with Jekyll and GitHub Pages for fast load times, simple deployment, and zero-maintenance static hosting.
